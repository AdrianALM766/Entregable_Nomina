Leyenda del Diagrama:
• Monigote UML (Actor): Representa al usuario final (Empleado de Planta) que interactúa directamente con el portal.
• Caja central («sistema de software»): Delimita la frontera del nuevo Portal de Autoconsulta de Desprendibles, conteniendo los casos de uso primarios.
• Cajas rectangulares externas («sistema externo»): Representan los sistemas periféricos independientes con los que interactúa el portal (Sistema de Nómina en Delphi y Servicio de Correo/Notificaciones).
• Flechas con etiquetas: Indican la dirección de la interacción y el protocolo de comunicación utilizado (HTTPS, TCP / SQL Read-Only, SMTP).

Párrafo de Lectura (30 segundos):
La vista de contexto representa el Portal de Autoconsulta como un sistema desacoplado que aísla la operación del sistema de nómina legado en Delphi. El Empleado de Planta accede mediante HTTPS para autenticarse (Cédula + PIN) y consultar/descargar su desprendible quincenal en PDF. Para disponer de la información sin escribir ni modificar la base de datos original, el caso de uso de extracción consulta en modo solo lectura (TCP / SQL Read-Only) la base de datos de Delphi, mientras que el caso de uso de notificaciones se conecta vía SMTP a un servicio de correo externo para alertar a los trabajadores cuando la nómina está disponible.

Leyenda del Diagrama:
• Monigote UML: Representa al Empleado de Planta accediendo desde su dispositivo móvil o PC.
• Cajas internas («contenedor»): Componentes ejecutables y de almacenamiento propios del Portal de Autoconsulta (Frontend Web, API Backend en Spring Boot y BD MariaDB).
• Cajas externas («sistema externo»): Sistemas de software fuera de la frontera del portal (Base de Datos del Sistema Legado en Delphi y Servidor SMTP de Correo).
• Flechas con etiquetas: Indican el protocolo de comunicación, formato de datos o driver utilizado entre cada contenedor.

Párrafo de Lectura (30 segundos):
La vista de contenedores desglosa la arquitectura del portal en una estructura desacoplada en N-Capas. El Empleado de Planta accede a la interfaz Frontend Web (HTML5 + Bootstrap 5) mediante HTTPS (Puerto 443). El Frontend interactúa vía JSON / HTTPS (API REST) con el API Backend (Java 21 / Spring Boot 3.x), donde residen la lógica de autenticación JWT y las reglas de negocio. La API Backend persiste y consulta la información del portal en la Base de Datos MariaDB 10.x a través de Spring Data JPA (Hibernate) / TCP. Para garantizar el aislamiento sin alterar el sistema antiguo, el Backend ejecuta consultas periódicas de extracción en modo solo lectura (JDBC Read-Only / TCP) sobre la Base de Datos Legada en Delphi, e integra un Servicio de Correo externo mediante SMTP para la notificación automática de desprendibles.
